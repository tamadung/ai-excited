A phoenix bursting upward out of a ring of fire, wings spread wide across the whole frame. Its feathers burn molten gold, crimson and blazing orange, with a white-hot eye and a trail of embers and sparks dissolving into tiny constellations against a deep indigo night sky. One look is meant to hit with a jolt: the bird is mid-burst, all colour and light driving toward a single thrilling moment, and the bold silhouette still reads clearly when the image is small.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (1024×1024, JPEG) to the output directory. Run it twice and the bytes are identical.
